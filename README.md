# AI Roleplay MultiCharacter

คู่มือภาษาไทยสำหรับสร้าง AI Roleplay แบบหลายตัวละคร พร้อมเนื้อหา 19 บทและแม่แบบคัดลอก 17 ชุด

## เปิดในเครื่อง

ดับเบิลคลิก `open-in-browser.command` หรือเปิดเซิร์ฟเวอร์ในโฟลเดอร์แม่ด้วย:

```bash
python3 -m http.server 4173
```

จากนั้นเปิด `http://127.0.0.1:4173/roleplay-studio/`
